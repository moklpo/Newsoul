# StratBack India

StratBack India is a specialized platform for Indian stock traders to rapidly develop, backtest, and optimize trading strategies for NSE/BSE markets using high-fidelity historical data.

## Project Structure

- `backend/`: FastAPI application for the backtesting engine and data management.
- `frontend/`: React application (Vite-based) for the trader dashboard.

## Getting Started

### Backend

1. Navigate to `backend/`.
2. Install dependencies: `pip install -r requirements.txt`.
3. Run the API: `uvicorn main:app --reload`.

### Frontend

1. Navigate to `frontend/`.
2. Install dependencies: `npm install`.
3. Run the development server: `npm run dev`.
